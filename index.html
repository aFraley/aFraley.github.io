What I Build

I build production software end to end: the interface someone uses, the API and data model behind it, the pipeline feeding it, and the infrastructure holding it up. Nine-plus years of Python and Django on the backend, Vue and React on the frontend, and PostgreSQL/PostGIS underneath, mostly on systems where something physical depends on the answer being right. Geospatial, computer vision, and drone data are where I have gone deepest.

Products, End to End

At Alynix I was lead full-stack developer and architect across three drone-inspection products, reporting to the CTO. Decker, a bridge deck inspection platform, I built from the data model up: Django/DRF and Java/Spring APIs, a multi-tenant PostGIS model with organization-scoped access control, and a Vue 3 frontend covering flight planning, project management, and report visualization. Users plan whole corridors of bridges, upload the data once flown, and get a report viewable live in the app, with thermal deck maps rendered over a cloud-optimized GeoTIFF. It shipped to DOT pilots in multiple states. Alongside it: Decker FlightOps, an MQTT command-and-control and telemetry system for the drone fleet, and GroundControl, a photogrammetry and 3D visualization platform for civil engineering.

Frontend & Interfaces

Vue 3 is my production depth, with React and React Native across years of client work. The interfaces I like building are the data-heavy ones that non-engineers have to actually use: map-driven dashboards in Mapbox GL and MapLibre, point cloud and 3D scene views in three.js, and a drag-and-drop pipeline builder that let customers compose their own photogrammetry processing instead of fighting rigid presets.

Backend & Data

Django and Django REST Framework backed by PostgreSQL/PostGIS are the core of my work: multi-tenant architecture, schema design and query tuning on large spatial tables, REST API design, and background processing with Celery. Java/Spring Boot, FastAPI, and Go when a service calls for it. Ingestion pipelines orchestrated with Prefect and Celery take raw input through processing to a checked result.

Imagery, Computer Vision & Geospatial

I architected and built Decker's thermal imaging pipeline: drone-captured infrared imagery every 30 minutes through the day, stitched across thousands of frames, filtered to remove vehicles and people, and analyzed as a time series to find subsurface defects, with parallel processing so multiple inspections run concurrently. It cut manual review from weeks to days. For GroundControl, ETL pipelines producing point clouds, classified point clouds, and orthorectified imagery with PDAL, ODM, and GeoPandas. Satellite work too: Sentinel-2 and Sentinel-1 SAR, STAC, and COGs.

Infrastructure Under It

I run what I build. Production AWS (EKS, RDS, Lambda, S3, SES) provisioned with Terraform, containerized with Docker, and deployed on Kubernetes with CI/CD. At Alynix that included consolidating services onto a shared multi-tenant Postgres RDS and near-zero-downtime migrations of multi-GB PostGIS databases, with runbooks and rollback snapshots.
